CHROME / EDGE 本地扩展

Pixel Flow
使用说明

把图片、文字、任务和生成结果放进一张无限画布。兼容浏览器模式和 API Key 模式，可按任务自由选择。

版本 0.2.6 支持 Chrome / Edge 图片容器与批量结果 本地保存画布
先做这一件事：请先把收到的 ZIP 完整解压。安装时选择解压后的 扩展程序 文件夹，不能直接选择 ZIP，也不要选择最外层“分享版”文件夹。

一、使用前准备

浏览器模式

  • macOS 或 Windows 电脑。
  • 最新版 Chrome 或 Edge 浏览器。
  • 一个已登录并能正常使用 chatgpt.com 的 ChatGPT 账号。
  • 不需要 API Key、Node.js 或运行命令。

API Key 模式

  • macOS 或 Windows 电脑。
  • 最新版 Chrome 或 Edge 浏览器。
  • 可用于 aihub.rbmanon.cn 的 API Key。
  • Node.js 20 或更高版本。
  • 安装并运行 Pixel Flow API Worker。
  • 不需要登录 ChatGPT 网页账号。

二、安装扩展

Chrome 安装方法

打开扩展管理页在地址栏输入 chrome://extensions，按回车。
打开“开发者模式”找到页面右上角的“开发者模式”开关并打开。
点击“加载已解压的扩展程序”在弹出的窗口里，选择本分享包中的 扩展程序 文件夹。
固定扩展图标点击浏览器右上角的拼图按钮，把“Pixel Flow｜像素流”固定到工具栏。

Edge 安装方法

打开扩展管理页在地址栏输入 edge://extensions，按回车。
打开“开发人员模式”找到页面左侧或右侧的“开发人员模式”开关并打开。
点击“加载解压缩的扩展”选择本分享包中的 扩展程序 文件夹。
固定扩展图标把“Pixel Flow｜像素流”固定到浏览器工具栏。

浏览器可能提示这是“开发者模式扩展”，这是手动安装本地扩展时的正常提示。只要分享包来源可信即可继续使用。

三、第一次使用

先登录 ChatGPT正常打开 https://chatgpt.com/，确认已经登录并能发送消息。
打开无限画布点击浏览器工具栏中的“Pixel Flow”图标。
放入图片或文字点击左侧“上传图像”或“新增文字节点”；也可以按 Command + V（Windows：Ctrl+V）粘贴。
新建任务或图片容器点击底部“新增任务”，再从图片或文字右侧的紫色连接点拖线到任务卡左侧。如果需要逐张执行，先选中多张图片再点“新建图片容器”，把容器连到任务。
填写要求并运行在任务卡输入提示词，按需选择图像比例，然后点击紫色“运行任务”按钮。
查看结果图片结果会在任务右侧水平并排；每张图右上角的下载按钮可保存原图。同一张任务卡再次运行，会继续原来的 ChatGPT 对话。

四、常用操作

创建和连接

双击画布空白处：快速新建图片、文字或任务。

从节点右侧拖线到空白处：可以自动新建任务并连接。

拖动任务卡里的小缩略图：调整多张参考图的顺序。

移动和删除

按住节点拖动：节点会实时跟随鼠标。

选中节点后按 Backspace 或 Delete：删除节点和相连的线。

按 Command + Z（Windows：Ctrl+Z）：撤销当前画布的最近动作，包括删除节点、移动节点和新增任务。

双指平行滑动：快速平移画布；双指并拢或张开可缩小、放大。

复制图片与容器

选中图片、生成结果或容器 + Command/Ctrl+C：复制画布节点。

Command/Ctrl+V：粘贴图片或容器副本，会自动错开。单选图片或生成结果时，同时可粘贴真实图片到聊天工具。

容器的多图向外粘贴依赖 macOS 与聊天工具对多图剪贴板的支持。当前不能稳定作为多张独立附件粘贴，此项标记为待解决；容器的画布内部复制不受影响。

保存和内存

节省内存：关闭可以安全关闭的任务网页，但保留对话地址。

备份画布：保存完整的画布、连线和图片数据。

删除扩展前请先备份，否则该浏览器里的本地画布数据可能一起被删除。

五、API Key 生图

保存 API Key点击顶部“API 设置”，确认接口、模型与质量，然后输入并保存完整 Key。
确认任务模式新建任务和新建生图模板默认使用 API；需要时可在任务卡中手动切换为 GPT-web。已有任务保留原先保存的模式。
运行并回写点击“运行任务”。纯文字任务调用 generations；参考图通过 JSON Base64 Data URL 调用 edits；返回图片自动写回画布。
数据边界：API Key 只保存在当前浏览器本地；API 模式会把任务提示词和连接的参考图片发送到 aihub.rbmanon.cn。

Windows API Worker

安装 Node.jsWindows 10 / 11 需要 Node.js 20 或更新版本；浏览器模式不需要此步。
安装登录自启在 Pixel Flow 目录运行 npm run api-worker:install:windows，无需管理员权限。
管理 Worker手动启动用 npm run api-worker:start:windows，卸载用 npm run api-worker:uninstall:windows。

六、常见问题

点击“运行任务”后没有正常生成

先打开 ChatGPT 网页，确认账号已登录、没有验证码或使用次数限制。然后刷新 ChatGPT 页面和画布页面，再运行一次。

任务提示“需要手动处理”

点击任务卡上的“打开真实对话”，在网页里完成登录、验证码或其他提示，处理完后回到画布重新运行。

更新分享包后，界面还是旧的

打开扩展管理页，找到“Pixel Flow｜像素流”并点击重新加载按钮；再刷新画布和 ChatGPT 对话页。

重新打开浏览器后任务网页不见了

这是正常的节省内存功能。画布仍会保存原对话地址，再次运行任务或点击“打开真实对话”就会重新打开。

能不能直接双击 index.html 使用？

不能。必须按照前面的步骤，把 扩展程序 文件夹加载到 Chrome 或 Edge。直接双击网页文件无法使用浏览器权限。

七、安全与隐私说明

  • 工具使用你自己已经登录的 ChatGPT 网页账号，不读取或保存 ChatGPT 密码。
  • 画布、连线和图片保存在安装该扩展的浏览器本地数据库中。
  • 扩展的网页访问范围只包含 https://chatgpt.com/*。
  • 工具不会绕过 ChatGPT 的登录、验证码、套餐限制或使用次数限制。
  • ChatGPT 网页改版后，网页识别规则可能需要更新。

建议：重要项目定期使用“备份画布”，并把备份文件保存到安全位置。

八、Codex 结构化操作（可选）

普通手动使用 Pixel Flow 不需要 Bridge。如果需要让 Codex 直接操作真实画布，可在项目目录运行 npm run bridge:install。

安全边界：Bridge 只监听本机 127.0.0.1:43128。Codex 可通过 MCP 读取画布、新建和执行任务、撤销、移动节点及下载图片。详细命令见 COMMAND_API.md。
