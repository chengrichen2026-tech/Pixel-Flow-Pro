Pixel Flow v0.2.6｜使用说明
=============================

Pixel Flow 是一个 Chrome / Edge 本地扩展。
它把图片、文字、任务和结果组织在无限画布中，并兼容浏览器模式和 API Key 模式。

本说明对应当前包版本 v0.2.6（2026-08-27 功能更新）。

浏览器模式：
- 需要一个已登录并能正常使用的 ChatGPT 网页账号。
- 不需要 API Key、Node.js 或运行命令。

API Key 模式：
- 需要可用于 aihub.rbmanon.cn 的 API Key。
- 需要 Node.js 20 或更高版本，并安装运行 Pixel Flow API Worker。
- 不需要登录 ChatGPT 网页账号。

一、安装前
----------
1. 先把收到的文件夹或 ZIP 完整解压。
2. 安装时必须选择解压后的“扩展程序”文件夹。
3. 不能直接选择 ZIP，也不要选择最外层项目文件夹。

二、Chrome 安装
---------------
1. 在地址栏输入：chrome://extensions
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本分享包里的“扩展程序”文件夹。
5. 点击浏览器右上角拼图按钮，把“Pixel Flow｜像素流”固定到工具栏。

三、Edge 安装
-------------
1. 在地址栏输入：edge://extensions
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本分享包里的“扩展程序”文件夹。
5. 把“Pixel Flow｜像素流”固定到浏览器工具栏。

四、第一次使用
--------------
1. 打开 https://chatgpt.com/，确认已经登录并能正常聊天。
2. 点击浏览器工具栏里的“Pixel Flow”图标。
3. 上传图片、添加文字，或在画布空白处按 Command+V（Windows：Ctrl+V）粘贴。
4. 新建一个生图任务节点。
5. 从图片或文字右侧的紫色连接点拖线到任务卡左侧连接点。
6. 填写提示词、选择图像比例，然后点击紫色“运行任务”。
7. 图片结果和文字结果会自动出现在任务右边。
8. 同一张任务卡再次运行，会继续原来的 ChatGPT 对话。

五、Mac 触控板与快捷键
----------------------
- 双指平行滑动：移动画布，移动速度约为默认值的 2 倍。
- 双指并拢或张开：缩小或放大画布。
- 选中节点后按 Backspace 或 Delete：删除节点和相连的线。
- 输入框正在编辑时，Backspace 只删除文字，不会误删节点。
- Command+Z（Windows：Ctrl+Z）：撤销当前画布的最近动作（删除节点、移动节点或新增任务）。
- Command+C / Command+V（Windows：Ctrl+C / Ctrl+V）：复制粘贴图片、图片容器或生图任务。生图任务副本保留提示词、比例、模式和输入连线，运行状态重置为尚未运行。
- Command+C（Windows：Ctrl+C）：复制已选中的普通图片、生成结果或图片容器。单选图片/结果还会把真实图片写入系统剪贴板，可直接粘贴到聊天工具。
- Command+V（Windows：Ctrl+V）：粘贴最近复制的图片或图片容器；连续粘贴会自动错开。在输入框、文本框中仍使用系统原生复制粘贴。

六、Windows API 模式
-----------------------
- 浏览器模式无需安装本地服务。
- API Key 模式请先安装 Node.js 20+，再运行：npm run api-worker:install:windows
- 手动启动：npm run api-worker:start:windows
- 卸载：npm run api-worker:uninstall:windows
- 安装器只写入当前 Windows 用户的“启动”文件夹，无需管理员权限。

七、常用操作
------------
- 图片容器：选中一张或多张图片后点击底部“新建图片容器”，再连到生图任务。容器内每张图会各自执行；容器外同时连入的图片会作为每次生图的共享参考图。
- 结果图：同一任务的结果会在任务右侧水平并排，每张图右上角的下载按钮可直接保存。
- 复制图片容器到聊天工具：容器内图片的画布内部复制可用；但 macOS 剪贴板和部分聊天工具不能稳定接收多张独立图片，“容器→聊天工具多附件粘贴”仍为待解决限制。
- 底部“生图模版”图标当前为开发中占位，点击仅会提示“功能还没想好，开发中！”。
- 双击画布空白处：快速新建图片、文字或任务。
- 按住节点拖动：节点实时跟随鼠标。
- 从节点右侧拖线到空白处：自动新建任务并连接。
- 点击“节省内存”：关闭可以安全关闭的任务网页，但保留对话地址。
- 使用“备份画布”：保存完整画布、连线和图片数据。

八、遇到问题
------------
- 运行没有反应：确认 ChatGPT 已登录，再刷新 ChatGPT 页面和画布页面。
- 显示“需要手动处理”：打开真实对话，完成登录、验证码或网页提示。
- 更新后还是旧界面：打开扩展管理页，点击 Pixel Flow 的重新加载按钮，再刷新画布。
- 任务网页被关闭：这是节省内存功能，再次运行或打开真实对话会恢复。
- 不能直接双击 index.html 使用，必须通过浏览器扩展管理页安装。

九、安全说明
------------
- 工具不读取或保存 ChatGPT 密码。
- 画布数据保存在安装扩展的浏览器本地数据库中。
- 扩展网页访问范围只包含 https://chatgpt.com/*。
- 工具不会绕过登录、验证码、套餐限制或使用次数限制。
- 删除扩展前请先备份，防止本地画布数据一起被删除。

十、生图模式
------------
- API：新建任务和新建生图模板的默认模式；首次使用前点击顶部“API 设置”保存 Key。
- GPT-web：需要时可在任务卡中手动切换，继续使用已登录的 ChatGPT 网页账号。已有任务保留原先保存的模式。
- API Key 只保存在当前浏览器本地，不进入画布、备份、日志或源码。
- API 模式会把任务提示词和连接的参考图片发送到 aihub.rbmanon.cn。
- 纯文字任务调用 /v1/images/generations；带参考图任务调用 /v1/images/edits，并以 JSON Base64 Data URL 传图。
- API 返回的 Base64 图片会保存到原画布，并生成普通结果节点。

十一、Codex 结构化操作（可选）
-------------------------------------
- 普通手动使用 Pixel Flow 不需要安装 Codex Bridge。
- 需要让 Codex 操作真实画布时，在 Pixel Flow 项目目录运行：npm run bridge:install
- Bridge 只监听本机 127.0.0.1:43128，不是公网服务。
- Codex 通过 Pixel Flow MCP 可读取画布、新建/执行生图任务、撤销、移动节点和下载图片。
- 详细命令、安全边界和卸载方式见 COMMAND_API.md。

推荐优先打开“先看这里-使用说明.html”，里面有完整图文说明。
