当前版本 v0.3.15
=================

任务体验
- 发布当前完整源码、TaskRun 后台重构、三模式紧凑任务卡和用户选择的 D“柔和分区”视觉。
- 任务卡恢复改版前的紧凑结构，只保留 GPT Web、Team Cloud、API 三个主模式。
- GPT Web 可选择本机或团队；团队即原 Team Web 底层链路。Team Cloud 可选择 Flare 或 Sunburst；API 固定 gpt-image-2。
- 底层继续兼容 api / browser / team / team_web，旧画布无需迁移。
- 状态统一由 TaskRun 投影，明确区分排队、准备环境、上传、发送、等待执行机、生成、写回、完成、失败、等待手动处理和取消。
- 活动任务可取消；失败或取消后可重试；有可恢复团队 Job 时可重新下载已有结果，不重复生图。
- 普通任务、图片容器批量、模板运行和失败重试统一通过 RUN_TASKS 调度。

运行可靠性
- TaskRun 已成为运行写入、启动恢复和 provider 对账的权威来源；TaskNode 只保留任务定义、UI 投影和批量父级汇总。
- TaskRun、任务卡状态、结果资产与结果节点在同一 IndexedDB 事务中提交。
- 终态任务不会在扩展重载后重新提交；重复、迟到或冲突结果不会重复创建节点。
- ChatGPT 对话 URL 提前持久化，页面监听改为 DOM 变化唤醒并保留定时兜底。
- API Worker 使用持久 Job 和 alarm 恢复，扩展重载后可继续读取既有任务结果。

Team Cloud / Team Web
- 成员浏览器只保存成员令牌；固定 Cloudflare 中继托管平台访问 Key 并转发任务箱请求。
- 团队中任意一台在线网页执行机都可领取 GPT Web 团队任务，提交电脑无需配对；已授权成员的新任务默认选择 GPT Web 团队。
- GPT Web 团队任务不消耗 Team Cloud 每日额度；成员令牌仍用于身份和任务归属。
- Team Cloud 结果优先经妙搭任务箱代理下载；代理网络或 5xx 故障时可回退仍有效的签名直链，401/403 不绕过。
- Team Web 使用任务级 single-flight，避免原监听与恢复监听重复回传、下载或完成。
- 协议 v6 优先使用带字节数和 SHA-256 校验的多图 bundle；超过 18 MB 自动回退旧分块，旧执行机不领取新协议任务。
- 协议 v8 支持提交方取消 uploading / queued / running Job，并拒绝 Worker 的迟到写回。
- 任务卡与任务箱会显示等待执行机上线、执行机忙、需要手动发送、正在生成和正在写回。

画布、素材与模板
- 支持图片、文字、任务、结果和图片容器；容器逐图生成，容器外图片作为共享参考图。
- 图片、结果、容器和任务支持画布内复制粘贴；单张图片或结果可同时复制到系统剪贴板。
- 每画布独立撤销覆盖新增任务、移动、删除和复制任务。
- 左侧提供提示词库、产品素材、参考图库和生图模板；各库支持管理、标签、备份与导入。
- 生图模板同步使用三个主模式及对应二级选择，并继续保存四种底层兼容值。
- 底部工具栏“生图模版”仍为开发中占位；正式模板入口在左侧生图模板库。

工程与跨平台
- 后台数据库、TaskRun、队列、协议、标签页管理、provider I/O 和结果投影已拆为可独立测试的 TypeScript 模块。
- 构建会先清空并重建扩展 assets 目录，不再保留旧哈希 chunk。
- Windows CI 不再断言 Windows 不支持的 POSIX 0600 mode；Ubuntu、macOS、Windows 测试和构建均通过。

重要提示
========

- 更新后必须在扩展管理页点击“重新加载”，再刷新 Pixel Flow 和相关 ChatGPT 页面。
- 删除扩展前先备份画布和资产库。
- API Key、团队凭证和网页生图机令牌只保存在当前浏览器本地，不进入公开源码或画布备份。
- 构建成功不代表当前浏览器已加载新版；涉及生图的更新必须以真实结果写回画布为完成标准。
