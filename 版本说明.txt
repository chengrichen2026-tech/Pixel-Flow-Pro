本版本主要变化：
- 新增 Windows 10 / 11 API Worker 安装、手动启动和卸载脚本。
- Windows 登录自启无需管理员权限，并提供启动健康检查。
- macOS API Worker 安装器改为动态路径，GitHub 克隆到任意目录都可安装。
- ChatGPT adapter v15 修复扩展重载后重连和隐藏新对话参考图上传暂停。
- 每张任务卡新增“浏览器 / API Key”生图模式，默认保持浏览器模式。
- 新增本地 API Key 设置；Key 不进入画布、备份、日志或源码。
- API 纯文字生图使用 /v1/images/generations，参考图生图使用 /v1/images/edits。
- 多张参考图按网关已验证的 JSON `images[].image_url` Base64 Data URL 上传；不使用 multipart。
- API 结果复用原版 IndexedDB、任务队列和结果节点回写逻辑。
- API 请求增加 7 分钟超时；扩展重载后的中断任务不会自动重试，避免重复计费。
- 产品名称更新为 Pixel Flow，副标题为“AI 创意任务画布”。
- 界面更新为 Pixel Local 同款珍珠灰白、浅色点阵与荧光紫视觉系统。
- 普通连线和动态结果连线统一为紫色。
- Mac 触控板支持双指平移，以及双指并拢/张开缩放。
- 双指平移速度提高至 React Flow 默认速度的约 2 倍。
- 选中节点后支持 Backspace 或 Delete 删除；文字编辑状态不会误删节点。
- 保留原版成熟的画布、拖动、缩放、连线、任务队列和本地数据逻辑。
- ChatGPT 自动发送增加备用提交方式；失败时会提示手动处理。

核心功能：
- 无限画布管理图片、文字、任务和生成结果。
- 使用已登录的 ChatGPT 网页账号，无需 API Key。
- 支持多张参考图、提示词和图像比例要求。
- 支持图片结果和长文字结果返回画布。
- 最多同时运行 3 个任务，其他任务自动排队。
- 任务完成后自动释放可安全关闭的网页标签。
- 支持本地画布备份。

重要提示：
- 安装或更新后，需要在扩展管理页点击一次“重新加载”。
- 删除扩展前请先备份本地画布。
- ChatGPT 网页改版后，网页识别规则可能需要更新。
